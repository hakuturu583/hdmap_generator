roadgen

Describe roads, lanes and junctions in Python. The same network comes out as OpenDRIVE, an Autoware-ready Lanelet2 map, plain OpenStreetMap, a SUMO network, a ClipGT clip and a GPUDrive scene — all of them at once, and all of it in this tab.

github.com/hakuturu583/hdmap_generator
Starting Python…

The exports will appear here — one panel per file your script writes.

Python runs here as Pyodide, and roadgen is its own wheel built for it, so what you are running is the package rather than a demonstration of it. OpenDRIVE, SUMO, ClipGT and GPUDrive are drawn by roadgen-viewer, in the same wheel; the two OpenStreetMap exports go to Leaflet, which already knows how to draw a map in geographic coordinates.
